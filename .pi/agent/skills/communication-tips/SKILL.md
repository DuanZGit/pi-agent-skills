# 沟通表达与提示词

## 用户只需说
- "朋友生病了怎么回复"
- "怎么委婉拒绝借钱"
- "新年祝福语怎么写"
- "帮我写个提示词让AI回答健康问题"
- "怎么问AI能获得更好的回答"

## Agent 自动执行

### 话术查询
```bash
bash scripts/comm-template.sh <场景> [关系]

# 场景：sick/生病、reject/拒绝、festival/节日、thank/感谢、sorry/道歉、marriage/催婚
# 关系：close/亲密、normal/普通、formal/正式
```

### 提示词生成
```bash
bash scripts/prompt-builder.sh <类型>

# 类型：knowledge/知识、communication/沟通、content/内容、problem/问题
```

### 官方媒体参考
```bash
bash scripts/fetch-news.sh [类型]

# 类型：people/人民日报、xinhua/新华社、cctv/央视
```

## 核心原则

### 话术原则
1. **表达风格**：参考人民日报、新华社官方表达
2. **话术特点**：得体大方、温暖真诚、简洁有力、分寸恰当
3. **分层设计**：亲密版/普通版/正式版

### 提示词原则
1. **角色设定**：明确让AI扮演什么角色
2. **任务描述**：清晰说明要做什么
3. **输出格式**：规定怎么回答
4. **质量要求**：设定回答标准

## 官媒表达参考
- 值此XX之际，致以XX问候
- 承蒙关照，不胜感激
- 恭祝XX，阖家XX

## 常见场景速查
| 场景 | 要点 |
|-----|------|
| 关心问候 | 关心 + 具体帮助 + 祝福 |
| 委婉拒绝 | 肯定信任 + 说明困难 + 表达歉意 |
| 节日祝福 | 简洁 + 正面 + 有温度 |
| 表达感谢 | 具体说明感谢什么 |
| 表达歉意 | 承认问题 + 改进措施 |
