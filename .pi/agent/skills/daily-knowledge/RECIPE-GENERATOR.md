# 食谱生成指南 - Agent 用这个来生成任意菜品的食谱

## 核心原理

当用户问一道菜怎么做时，Agent 应该：

1. **识别菜品类型**：荤菜/素菜/汤品/主食/甜点
2. **确定烹饪方式**：炒/蒸/煮/炖/煎/炸/烤/凉拌
3. **查询相关原理**：从知识库获取科学原理
4. **生成完整食谱**：融合原理生成详细步骤
5. **标注营养信息**：提供每份营养成分
6. **提示常见错误**：避免失败的关键点

## 烹饪方式速查

### 炒（200-300°C，大火快炒）
**适用**：蔬菜、肉片、海鲜
**原理**：美拉德反应产生香味，快速锁住水分
**要点**：
- 锅热油热，冒烟前下菜
- 大火快炒，不超过3分钟
- 食材切小均匀
- 先炒硬的后炒软的

### 蒸（100°C，水蒸气加热）
**适用**：鱼、蛋、蔬菜、面食
**原理**：保留营养最多（90%以上），不产生有害物质
**要点**：
- 水开后再放食材
- 大火蒸制，中途不开盖
- 蒸鱼8-10分钟，蒸蛋15分钟

### 煮（100°C，水传导）
**适用**：汤类、粥、面条
**原理**：水溶性维生素会流失到汤中，但汤可回收
**要点**：
- 肉类冷水下锅去血沫
- 蔬菜热水下锅保色
- 汤要一起喝

### 炖（85-95°C，小火慢炖）
**适用**：肉类、骨头、根茎蔬菜
**原理**：胶原蛋白水解成明胶，肉质软烂
**要点**：
- 大火烧开，小火慢炖
- 中途不加冷水
- 盐中途放更入味

### 煎（150-200°C，油脂传导）
**适用**：鱼、肉、蛋、豆腐
**原理**：表面焦化形成美拉德反应外壳，锁住水分
**要点**：
- 热锅冷油防粘
- 不要频繁翻动，等定型再翻
- 中火慢煎

### 炸（170-190°C，高温油）
**适用**：肉类、蔬菜、面食
**原理**：快速脱水焦化，形成酥脆外壳
**要点**：
- 油温要够（筷子冒泡）
- 分次炸：第一次炸熟，第二次炸脆
- 炸完沥油

### 烤（150-250°C，热辐射）
**适用**：肉类、面包、蔬菜
**原理**：美拉德反应+焦糖化反应
**要点**：
- 预热烤箱
- 肉类烤前回温，烤后静置
- 用锡纸包裹减少有害物质

### 凉拌（常温，不加热）
**适用**：蔬菜、豆制品、熟肉
**原理**：保留营养100%，调味料渗透入味
**要点**：
- 食材洗净
- 先加盐杀水
- 冷藏后更佳

### 焯水（100°C，短时间水煮）
**适用**：蔬菜、肉类预处理
**原理**：去草酸、去农残、去腥
**要点**：
- 水开下锅，加盐油保色
- 蔬菜30秒-2分钟
- 肉类冷水下锅去血沫

## 食材处理速查

### 肉类通用
```
去腥：冷水浸泡30分钟，加料酒姜片焯水
嫩滑：加淀粉、蛋清腌制15分钟
切法：逆纹切，口感更嫩
焯水：冷水下锅，煮开撇沫
保存：冷冻可保存3个月，冷藏3天
```

### 鱼类通用
```
去腥：盐搓洗，料酒姜片腌制10分钟
处理：去鳞去内脏去鳃，斜刀切花刀
蒸制：水开后上锅，8-10分钟
保存：冷藏1-2天，冷冻1个月
```

### 蔬菜通用
```
清洗：先洗后切，减少营养流失
焯水：水开下锅，加盐油保色，30秒-2分钟
炒制：大火快炒，保持翠绿
保存：冷藏3-5天，叶菜类尽快食用
```

### 豆腐通用
```
定型：盐水浸泡30分钟
去腥：焯水2分钟
煎制：热锅冷油，不要急着翻面
保存：冷藏2-3天，冷冻可保存1个月
```

### 蛋类通用
```
煮蛋：冷水下锅，水开后6分钟（溏心）/10分钟（全熟）
炒蛋：大火快炒，蛋液凝固即出锅
蒸蛋：蛋水比1:1.5，中火蒸12-15分钟
保存：冷藏2周，避免与气味重的食物放一起
```

### 海鲜通用
```
去腥：料酒姜片腌制，葱姜蒜爆香
烹饪：大火快炒，避免过老
蒸制：水开后上锅，视大小3-8分钟
保存：冷藏1-2天，建议当天食用
```

## 调味速查

### 基础调味
```
盐：提鲜，炒菜最后放，炖肉中途放
糖：中和酸味，提鲜，炒糖色上色
酱油：生抽调味，老抽上色
醋：去腥，软化肉质，保护维生素C
料酒：酒精挥发带走腥味
```

### 香料
```
姜：去腥增香，爆香用
蒜：杀菌去腥，爆香或凉拌
葱：去腥增香，出锅前放
花椒：麻味，川菜必备
八角/桂皮：炖肉增香
干辣椒：辣味，根据口味调整
香叶：炖肉增香，去腥
```

### 万能酱汁
```
糖醋汁：糖3:醋2:生抽1:料酒1
红烧汁：生抽2:老抽1:料酒2:糖1
蒜蓉汁：蒜末+生抽+醋+糖+香油
凉拌汁：生抽+醋+蒜+辣椒油+糖
鱼香汁：糖2:醋2:生抽1:料酒1:豆瓣酱1
宫保汁：糖2:醋1:生抽1:料酒1:淀粉水
```

### 调味原则
```
1. 分层调味：基础味（盐糖）→ 风味味（酱油醋）→ 香味味（葱姜蒜）
2. 适时调味：盐早放入味，醋早放挥发，酱油晚放保色
3. 适量调味：宁少勿多，逐步添加
4. 平衡调味：酸甜苦辣咸，相互衬托
```

## 生成示例

用户问："青椒炒肉丝怎么做？"

Agent 生成：
```
【青椒炒肉丝 - 家常版】

【食材】
主料：猪里脊肉200g、青椒2个
腌料：料酒1汤匙、生抽1茶匙、淀粉1茶匙、蛋清半个
调味料：生抽1汤匙、老抽1茶匙、盐1/2茶匙、糖1/4茶匙
辅料：蒜片3瓣、食用油3汤匙

【步骤】
1. 切肉丝：猪里脊逆纹切丝，加腌料抓匀腌15分钟
   【原理】逆纹切切断肌纤维，口感嫩；淀粉蛋清包裹锁水

2. 切青椒：青椒去籽切丝
   【原理】大小与肉丝一致，受热均匀

3. 炒肉丝：热锅加2汤匙油，油热放肉丝快速划散，变色盛出
   【原理】大火快炒锁住水分，变色即熟不会老

4. 炒青椒：锅中加1汤匙油，放蒜片爆香，加青椒丝大火翻炒1分钟
   【原理】大火快炒保持翠绿

5. 合炒：倒回肉丝，加生抽、老抽、盐、糖，翻炒均匀
   【原理】调味料快速翻炒均匀

6. 出锅：装盘

【营养信息】（每份）
- 热量：约320千卡
- 蛋白质：约25克
- 脂肪：约18克
- 碳水化合物：约12克
- 维生素C：约80毫克（青椒提供）

【成功关键】
- 肉丝要逆纹切，腌制15分钟
- 大火快炒，肉丝变色就盛出
- 青椒不要炒太久，保持脆度

【常见错误】
- 肉丝切太粗，炒不熟 → 逆纹切细丝，约0.3cm宽
- 火太小，肉丝出水变老 → 大火快炒，变色即出
- 青椒炒太久，变软变黄 → 最后下锅，翻炒1分钟即可

【交叉引用】
- [[猪里脊肉]] - 肉类处理方法
- [[青椒]] - 蔬菜保存和营养
- [[美拉德反应]] - 炒制原理
- [[番茄炒蛋]] - 类似家常菜
```

## 健康烹饪建议

### 减油技巧
```
1. 使用不粘锅，减少用油量
2. 先焯水再炒，缩短炒制时间
3. 用喷油壶，均匀喷洒
4. 蒸、煮、凉拌代替炒、煎、炸
```

### 减盐技巧
```
1. 使用天然调味料（葱姜蒜、香料）
2. 酱油、豆瓣酱等含盐调味料减少用量
3. 出锅前放盐，减少用盐量
4. 使用低钠盐
```

### 保留营养技巧
```
1. 蔬菜先洗后切，减少水溶性维生素流失
2. 大火快炒，缩短加热时间
3. 蒸比煮更能保留营养
4. 肉汤一起喝，回收流失的营养
```

### 食品安全提示
```
1. 生熟分开，避免交叉污染
2. 肉类要彻底煮熟
3. 冰箱不是保险箱，注意保质期
4. 剩菜彻底加热再食用
```
